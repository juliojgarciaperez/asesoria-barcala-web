PROMPTS PARA GENERACIÓN DE IMÁGENES — ASESORÍA BARKALA
========================================================

Cómo usarlo
-----------
1. Copia el PROMPT de cada bloque y pégalo en ChatGPT con generación de
   imagen (GPT-4o, gpt-image-1 o DALL·E) o en cualquier otro generador.
2. Si la imagen sale con texto/letras (los modelos suelen escribir mal),
   pide: "Regenerate without any text, letters or signage."
3. Convierte el resultado final a WebP (calidad 82) antes de subirlo:
       cwebp -q 82 input.png -o output.webp
   o súbelo a https://squoosh.app y exporta WebP 82.
4. Guarda cada archivo en la RUTA exacta que aparece en cada bloque.
5. git commit -m "imágenes generadas" → el hook reconstruye y publica.


Guía de estilo COMÚN (incluir en todos los prompts)
----------------------------------------------------
- Editorial corporate photography. Realistic, not illustrated.
- Soft natural light, premium, calm, trustworthy mood.
- Color palette grounded in navy blue (#1F4E79), warm beige/cream,
  off-white and dark wood. Muted tones, no oversaturated colors.
- Shallow depth of field, sharp foreground.
- NO text, NO letters, NO logos, NO watermarks, NO recognizable faces,
  NO institutional names (Hacienda, AEAT, etc. visible).
- Leave clean negative space when noted.

Después de generar las imágenes
-------------------------------------------------------------------------
- Comprueba que el peso de cada archivo es ≤ 250 KB (WebP 82 lo cumple
  para las dimensiones indicadas).
- Mantén los nombres EXACTOS de archivo (la web ya los busca por ese
  nombre). Si quieres usar otros nombres, edita src/data/services.ts
  y src/components/Hero.astro / About.astro.
- Ejecuta:
       git add public/images public/og-image.jpg
       git commit -m "Añade imágenes generadas"
       git push
  El hook pre-commit regenerará /docs automáticamente y GitHub Pages
  publicará la web en unos segundos.
